# 試作45 自由制作カメラUI整理

- `じぶんでつくる → カメラから作る`の撮影画面を、BACK、HOME、シャッター、カメラ切替だけに整理した。
- 作品見本、SOURCE表示、比較、タイマー、デザインパネルを素材撮影中は非表示にした。
- シャッターで撮った画像を素材として解析し、そのまま写真、4方式、3つの小案を表示する画面へ進むようにした。
- 素材撮影では手認識と試着描画を起動せず、生のカメラ映像を素早く表示する。
- 写真から作る導線、ネイル生成、試着用カメラは維持した。
