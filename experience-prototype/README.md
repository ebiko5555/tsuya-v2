# 艶 II — 試着から作品へ 試作28

作品ページの見せ方は試作6を維持し、各作品のネイルを「5本で完成するサロンのセットデザイン」として組み直した試作。
自由に組み合わせる試着は「自分で作る」という別ページに分けた。

## 守っていること

- 母体は `01_艶II_ブラッシュアップ`
- MediaPipe、カメラ、手の追跡、爪の描画、撮影などの中核スクリプトは無変更
- 追加したのは、TRACE / SKINに寄せた外観、作品ページ、6種類の専用ネイル描画、自由制作ページ
- 作品ページに、実際に装着する5本のネイル見本を表示する
- 作品映像は暗くせず、元の縦横比と明るさで表示する
- 映像と文章・ネイル見本を上下に分離する
- 5本すべてを同じ柄にせず、主役・ベース・抜け感・質感・ポイントへ役割分担する
- 見本を大きくし、実際のサンプルチップに近い配置で見せる
- 作品側の試着ではカスタム操作パネルを表示しない
- `?mode=custom` のページだけ、既存の全カスタム機能を表示する
- 元サイトと元動画は上書きしない

## 体験の順番

1. 非対称に重なる映像から作品一覧へ入る
2. COLOR / SURFACE / SCULPT / LIGHT / HAND / TRACE の作品ページを選ぶ
3. 作品映像と5本のネイル見本を確認する
4. 「この作品を手にのせる」で、その作品専用ネイルが固定された試着へ入る
5. 固定試着では撮影とカメラ切替だけを残し、柄や色の変更UIは出さない
6. 自由に作りたい場合は、別ページの「自分で作る」へ移る
