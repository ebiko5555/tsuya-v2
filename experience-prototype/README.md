# 艶 II ― 試着から作品へ／試作1

現在正常に動く「艶 II」を母体に、試着体験の奥へ作品レイヤーを追加した構造確認用の試作。

## この試作で確かめること

1. 鑑賞者が最初に自分の手を映す。
2. デザイン、カラー、質感、スカルプ、光を操作する。
3. 現在選んでいる操作から「試着の先へ」を開く。
4. 同じ画面内で、COLOR / SURFACE / SCULPT / LIGHT / HAND / TRACEの作品レイヤーへ移る。
5. 「試着へ戻る」で、試着中の状態へ戻る。

作品一覧から試着へ進むのではなく、試着から作品世界が立ち上がる順番を優先している。

## 安全のために維持した部分

- MediaPipe Handsの読み込み・設定
- 21点の手の追跡とスムージング
- 爪の位置、角度、形、デザイン描画
- 23種の内蔵デザインとマイデザイン
- 5本別の色・デザイン指定
- 質感、スカルプ、光の軌跡
- 撮影、3秒タイマー、比較、設定復元、写真保存
- UIブラッシュアップ1「静かな鏡台」

上記の中核コードは作り直していない。既存の`index.html`末尾に、独立した作品レイヤー用のHTML・CSS・JavaScriptだけを追加した。
