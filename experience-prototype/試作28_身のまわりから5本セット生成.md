# 試作28 — 身のまわりから5本セット生成

## 実装したこと

- 自由制作の入口を`写真から作る / カメラから作る`の二つにした。
- 写真または現在のカメラ映像から、色、線の方向、模様の密度、明暗、特徴的な形を端末内で抽出する。
- `COLOR / PATTERN / LIGHT / MIX`の4方式から、それぞれ3種類の5本セットを生成する。
- 5本を同じ柄にせず、親指を特徴、中指を主役、薬指を光、小指を余白として役割分担する。
- 写真を爪へ直接貼り付けず、抽出値を作者が定めた描画規則へ渡して再構成する。
- 選んだセットは既存のネイル試着へ適用し、その後も色、質感、形、光を調整できる。
- 入力画像は外部サービスへ送信せず、ブラウザ内のCanvas処理だけで扱う。
- MediaPipe、手の追跡、既存作品ページ、作品別固定試着は変更していない。

## 確認

- 390 × 844 pxで写真選択、特徴表示、4方式、3案、5本見本、`TRY ON`が一画面に収まることを確認。
- 作品画像から8色、線密度、光量、方向を抽出できることを確認。
- `COLOR / PATTERN / LIGHT / MIX`ごとに異なる3案が生成されることを確認。
- 3案の選択状態が切り替わることを確認。
- 通常の作品ページでは`SOURCE`タブが表示されず、`WORKS / HOME / TRY ON / じぶんでつくる`が維持されることを確認。
- ブラウザ試験環境には実カメラがないため、カメラ映像の採集は公開後にiPhone実機で確認が必要。
