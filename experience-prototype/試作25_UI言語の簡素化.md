# 試作25 — UI言語の簡素化

## 修正したこと

- 作品ページの主ボタンを、大きな `TRY ON →` だけにした。
- `カメラでネイルを試す` を削除した。
- 作品一覧への戻り方を `WORKS`、作品切替を `WORKS — SWIPE →`、自由制作を `CREATE` に統一した。
- 作品入口を `ENTER`、試着入口を `TRY ON → START CAMERA` にした。
- 試着入口やカメラ内の作品識別表示から操作説明の日本語を削除した。
- 作品内容としての題名と解説文は残した。
- 動画、作品切替、版番号の維持、試着、MediaPipeと手の追跡処理は変更していない。

## 確認

- 390 × 844 pxで `TRY ON` が19pxの大きな文字として固定表示されることを確認。
- 作品ページの主な操作表示が `WORKS`、`SWIPE`、`TRY ON`、`CREATE`だけになったことを確認。
- `TRY ON`から `?try=作品キー&v=mobile25` へ移動することを確認。
- 試着入口が `TRY ON`、作品名、`START CAMERA`で表示されることを確認。
