# 試作2 構造案と動画配置

## 入口

黒い展示空間の上に、四角・楕円・斜めの面として作品映像を非対称に重ねる。最初に説明や作品一覧は置かず、「自分の手から、作品へ。」とカメラ開始だけを見せる。

## 試着と作品の関係

- デザイン／カラー → COLOR
- 質感 → SURFACE
- スカルプ → SCULPT
- 光 → LIGHT
- HAND と TRACE は作品画面の番号からさらに奥へ進む

試着中のカメラ画面に、現在の操作に対応する縦長の映像断片を置く。これは広告バナーではなく、試着画面に作品が侵入してくる窓として扱う。

## 動画配置

| レイヤー | 使用動画 | 役割 |
|---|---|---|
| COLOR | `0001-0600.mp4` | 色と模様が手全体へ増殖する |
| SURFACE | `video.mp4` | 金色の流体、膜、艶、反射 |
| SCULPT | `労働者ワイヤーフレーム.mp4` | 線による手の構造と立体 |
| LIGHT | `修士制作曼荼羅10-ベース動画.mp4` | 手、球体、粒子、発光 |
| HAND | `思唯手半回転影グラデ0001-0746.mp4` | 手の線画、身振り、思惟 |
| TRACE | `ホコリ２_モノクロ移行.mp4` | 粒子、影、消えていく痕跡 |

公開用には元動画を変更せず、長辺960px・24fpsの軽量MP4を `art-assets/` に別名で作成している。

## 実装上の境界

既存の3つのインラインスクリプトは母体と同一。作品導線は4つ目の独立スクリプトに分離し、タブの選択状態だけを読み取る。カメラ・MediaPipe・爪の座標計算には触れない。
