# 試作42 写真後の3案選択画面

- 写真を選んだ後の自由制作画面を、写真情報と`COLOR / PATTERN / LIGHT / MIX`の4方式だけに整理した。
- 方式を選ぶと別の全画面へ移り、生成した3案を大きな5本セットとして表示する。
- 3案から1案を選ぶまでは試着ボタンを無効にし、選択後にそのセットで試着へ進めるようにした。
- 既存の写真解析、3案生成、ネイル描画、カメラ試着機能は維持した。
