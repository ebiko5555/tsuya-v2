# 試作1の判断

## 現在の2サイト

### 艶 II

1枚の`index.html`内に、カメラ、MediaPipe Hands、爪描画、デザイン、カラー、質感、スカルプ、光、撮影、比較、保存がまとまっている。現在の操作感を守るため、中核JavaScriptは変更しない。

### TRACE / SKIN

「表面・膜・内部・痕跡・接続」という章、手と球の映像、3Dの手、作品アーカイブを持つ。現在は作品鑑賞の後に試着へ進む構造だが、コンテンツ自体は試着の奥の作品レイヤーとして再利用できる。

## 新しい体験順

```text
艶 II
  ↓
自分の手を映す
  ↓
デザイン・色・質感・形・光を試す
  ↓
いまの操作から作品へ
  ↓
COLOR / SURFACE / SCULPT / LIGHT / HAND / TRACE
  ↓
試着へ戻る
```

## 変更対象

- `index.html`
  - 既存CSSの後ろへ作品レイヤー用CSSを追加。
  - 既存操作パネルの末尾へ「試着の先へ」を追加。
  - 既存UIの後ろへ全画面作品レイヤーを追加。
  - 既存スクリプトの後ろへ独立した作品レイヤー制御を追加。
- `art-assets/`
  - 指定フォルダから複製した作品動画5点。
- `README.md`
  - 試作の目的、維持機能、素材対応を記録。

## 変更しない部分

- MediaPipeの設定と読み込み
- 手のランドマーク更新とスムージング
- カメラ描画ループ
- 爪の形、位置、角度、デザイン描画
- 撮影、比較、保存、設定復元
- 元の「艶 II」基礎版とブラッシュアップ版
- 元動画

## 検証基準

- 初期画面が従来の試着アプリに見える。
- 現在のタブに合わせて作品入口がCOLOR / SURFACE / SCULPT / LIGHTへ変わる。
- 作品レイヤー内で6分類を切り替えられる。
- 「試着へ戻る」でページを再読み込みせず元画面へ戻る。
- 390×844で文字と6分類ボタンが画面内に収まる。
- ブラウザの画面エラーがない。
