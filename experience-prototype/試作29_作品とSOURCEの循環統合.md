# 試作29 — 作品とSOURCEの循環統合

## 修正したこと

- 作品アプリと写真・カメラから作る機能を、別アプリではなく一つの循環する作品体験へ統合した。
- 各作品ページの`じぶんでつくる`から、作品番号を保持したままSOURCEへ移動する。
- SOURCE入口に元作品の映像、番号、分類、題名を表示する。
- 元作品の5本セットを自由制作の初期ネイルとして引き継ぐ。
- 写真・カメラから別のセットを生成した後も、`作品ネイル`で元のセットへ戻せる。
- SOURCEの左上を`WORK`にし、元作品ページへ戻る循環を作った。
- 直接SOURCEへ入った場合も、`WORKS → SOURCE → HAND`というサイト全体の流れを示す。
- ページ移動時に短いフェードを加え、別アプリへの遷移ではなく同じ作品内の移動に見えるようにした。
- MediaPipe、手の追跡、作品別ネイル、写真解析、3案生成は変更していない。

## 体験の流れ

`作品 → 作品ネイル → SOURCEで身のまわりから採集 → 自分の5本セット → TRY ON → 元作品`

## 確認

- 390 × 844 pxでCOLOR作品からSOURCEへ入り、`FROM 01 / COLOR / 色`が表示されることを確認。
- SOURCEの戻るボタンが元のCOLOR作品へ戻ることを確認。
- 元作品へ戻った後も`じぶんでつくる`のURLに`from=COLOR`が保持されることを確認。
- 写真から3案を生成した画面に、元作品と`作品ネイル`ボタンが表示されることを確認。
- 直接SOURCEへ入った場合はWORKSへ戻り、作品由来表示が出ないことを確認。
