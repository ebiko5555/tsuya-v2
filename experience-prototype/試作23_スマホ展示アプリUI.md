# 試作23 — スマホ展示アプリUI

## 修正したこと

- 作品ページだけにスマホ専用レイアウトを追加した。
- 作品動画を画面上部42svhの鑑賞領域へ固定した。
- 作品切替を横スワイプ式のカードナビへ変更した。
- 作品名、説明、ネイル見本を独立した縦スクロール領域へまとめた。
- `カメラでネイルを試す` と `自分で作る` を最下部の操作ドックへ固定した。
- 後半の作品を直接開いた場合は、選択中の作品カードが見える位置まで自動移動するようにした。
- PC版、トップページ、作品入口、高画質動画、作品別ネイル、MediaPipeと手の追跡処理は変更していない。

## 確認

- 390 × 844 pxで動画、作品ナビ、作品情報、試着ボタンが一画面のアプリUIとして表示されることを確認。
- 10作品を横スワイプで切り替えられることを確認。
- `10 / RONDO`を直接開いた場合も選択カードが画面内へ入ることを確認。
- 作品切替後も動画が動き、試着ボタンが固定表示されることを確認。
- ページ全体に横方向のはみ出しがないことを確認。
