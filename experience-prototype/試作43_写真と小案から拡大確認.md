# 試作43 写真と小案から拡大確認

- 写真選択後の画面で、選んだ写真を画面の約半分の高さへ拡大した。
- 写真の下に`COLOR / PATTERN / LIGHT / MIX`と、その方式から生成した3つの小さなネイル案を並べた。
- 小さな案を押すと、選んだ1案だけを大きく表示する全画面へ進む構成にした。
- 拡大画面はセット名と`TRY ON`だけに絞り、選択を促す説明文を削除した。
- 写真解析、ネイル生成、カメラ試着機能は維持した。
