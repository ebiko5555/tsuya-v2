# 試作3 作品別固定試着

## 構造

- 入口：6つの作品ページと「自分で作る」への分岐
- 作品ページ：映像、作品名、短い文章、「この作品を手にのせる」
- 作品別試着：作品専用ネイルを最初から固定装着。カスタムUIは非表示
- 自分で作る：色、柄、質感、長さ、形、光をすべて変更できる既存試着

ページは同じ中核アプリを共有し、URLで役割を分ける。

- `?work=COLOR`：作品ページ
- `?try=COLOR`：COLOR専用の固定試着
- `?mode=custom`：自分で作る

## 作品別ネイル

| 作品 | 固定するネイルの方向 |
|---|---|
| COLOR | 5本を異なる色と模様にし、手全体へ色彩が広がる構成 |
| SURFACE | 金・琥珀色のクロム、ニュアンス、大理石、パール、シェル |
| SCULPT | 淡いワイヤー柄、長いコフィン形、低い艶 |
| LIGHT | 青緑の水光、スターダスト、オーロラ、強い光の軌跡 |
| HAND | 肌に近い色、線、透け感、控えめな艶 |
| TRACE | 灰色と黒のマット、粒子、弱く残る白い光の軌跡 |

## 実装上の境界

MediaPipe、カメラ、手の追跡、爪の座標計算、撮影処理を含む既存3スクリプトは変更しない。作品別設定とページ分岐は4つ目の独立スクリプトで行う。
