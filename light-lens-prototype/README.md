# TSUYA — 作品と日常のあいだ

試作106の機能を母体に、10作品を主画面に置き、写真と試着を作品の後段へ組み直した特別試作です。通常版は変更していません。

## 体験の流れ

1. 起動直後から、全体が画面内に収まる10作品を番号・左右ボタン・スワイプで自由に切り替える
2. 心に残った作品で「この作品からつくる」を選ぶ
3. 作品ごとに組んだ、これまでの5本のネイルセットを大きく見る
4. その5本を直接手に重ねるか、「作品の線や形は残し、写真から色だけを取り出す」別のつくり方へ進む
5. 写真を選んだ場合も作品の構図は保ち、抽出色と接触させた3案をつくる
6. 「手に重ねる」でカメラ試着へ進む

## 実装上の扱い

- 母体: `../experience-prototype/index.html`（試作106 / mobile106）
- MediaPipe、試作30ベースの追跡、カメラ、爪位置、背景抑制、写真解析、撮影・保存は変更していない
- 作品から受け取る要素: 作品ごとに定めた5本の柄、質感、長さ、形
- 写真から受け取る要素: 解析済みの色彩パレット
- 作品だけの5本はランダム生成しない。写真を重ねる場合も、作品の柄・質感・形を基準に日常写真の色を加える
- 通常版の入口や公開パスは差し替えず、専用パスで公開する
