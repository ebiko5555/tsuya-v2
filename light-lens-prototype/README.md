# TSUYA — 光を連れていく試作

試作106の機能を母体に、作品鑑賞と写真からのネイル生成を一本道へ組み直した特別試作です。通常版は変更していません。

## 体験の流れ

1. 「光を受け取りにいく」から10作品を見る
2. 心に残った作品で「この光を連れていく」を選ぶ
3. 日常の写真を一枚ひらく
4. 選んだ作品の柄・光・質感と、写真から抽出した色が接触して3案になる
5. 「手へ戻す」でカメラ試着へ進む

## 実装上の扱い

- 母体: `../experience-prototype/index.html`（試作106 / mobile106）
- MediaPipe、試作30ベースの追跡、カメラ、爪位置、背景抑制、写真解析、撮影・保存は変更していない
- 作品から受け取る要素: 5本の柄、質感、長さ、形、光の軌跡
- 写真から受け取る要素: 解析済みの色彩パレット
- 最終ネイルは「作品の性質 × 日常写真の色」から決定する
- 通常版の入口や公開パスは差し替えず、専用パスで公開する
