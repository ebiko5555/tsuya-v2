# 艶 II — 手と光のアトリエ

ネイル試着アプリ「艶」を、追従精度・質感・軽さのために一から作り直した版。
単一のHTMLファイル1本で動く（ビルド不要）。

- 旧版（永久版）: https://ebiko5555.github.io/tsuya-atelier/ ← これはそのまま残してあります
- このフォルダ: `~/Desktop/tsuya-v2/index.html`

## 旧版から変えたところ

| | 旧版（艶） | この版（艶 II） |
|---|---|---|
| 手の検出 | `@mediapipe/hands` 0.4（開発終了した旧API） | `@mediapipe/tasks-vision` HandLandmarker（GPU実行） |
| 爪の位置 | 指先と第一関節の**2点**だけ。爪は常に平面 | 指ごとに**3Dの向き**を計算。傾き・奥行き・手の甲の向きを反映 |
| 描画 | 2Dキャンバス（CPU） | WebGL2シェーダー（GPU） |
| ツヤ | 白い楕円を重ねただけ。動かない | 環境の映り込みを毎フレーム計算。手を回すと光沢が実際に流れる |
| 検出の頻度 | 毎フレーム（60回/秒） | カメラの新しいフレームが来た時だけ（30回/秒）。重い時は自動で半分に |
| 解像度 | 常にカメラの解像度（1280×720） | 画面サイズに合わせる。省エネ／標準／きれいの3段階 |
| 光の軌跡 | 1点ずつCPUで円を描く | GPUでまとめて描く |
| デザイン | 12種 | **24種** |
| 爪の形 | 固定（long.html のみ5形状） | **6形状 + 長さ・幅スライダー**を本体に統合 |

### 「爪が指に貼り付いて見える」仕組み

手の甲の向き（手首・人差し指付け根・小指付け根の3点から算出）を基準に、指ごとの
「前・横・法線」の3軸を作って爪を置いています。だから手を回すと爪も一緒に回り、
横を向けば奥行きで細くなり、手のひら側を見せれば爪は自然に消えます。
親指だけは解剖学的に爪の向きが違うので、甲より橈側（親指側）に寝かせて補正しています。

## 操作

- **デザイン** … 24種＋自分で描く／写真を爪に乗せる
- **カラー** … 12色＋カラーピッカー＋写真から配色を吸い出す
- **形** … ナチュラル／ラウンド／アーモンド／スクエア／バレリーナ／スティレット、長さ・幅
- **質感** … ツヤ・濃さ・**追従**（ゆったり／標準／きびきび）・**画質**（省エネ／標準／きれい）
- **光** … 指先の軌跡のオンオフ・強さ・色、速度メーター表示

「追従」と「画質」は端末に合わせて調整するところです。
iPhoneが熱くなるなら 追従=ゆったり／画質=省エネ、手の動きに遅れを感じるなら 追従=きびきび。

## ローカルで試す

`艶II_ローカルで開く.command` をダブルクリック。ブラウザが開きます。
（カメラを使うので `file://` で直接開くと動きません。このスクリプトが小さなサーバーを立ち上げます）

止めるときは、開いたターミナルの窓で `control + C`。

## 必要なもの

- WebGL2対応のブラウザ（iOS 15以降のSafari、Chrome、Edge）
- カメラ
- 初回のみ通信（AIモデル約8MBをCDNから読み込みます。以後はブラウザのキャッシュに残ります）
