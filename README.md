# 艶 II

ネイル試着アプリ「艶」に、デザインと爪の形を足した版。

- 公開URL: https://ebiko5555.github.io/tsuya-v2/
- 旧版（永久版・無傷）: https://ebiko5555.github.io/tsuya-atelier/
- ローカル: `~/Desktop/tsuya-v2/index.html`

## 中身について

**追跡と描画のコードは旧版（`tsuya-atelier/long.html`）と同一です。** 1文字も変えていません。

一度WebGLと3Dハンドトラッキングで作り直しましたが、追跡が旧版より悪化し、
Chromeでは特にひどくなったため全て破棄しました。実際に効いていたのは
旧版の「画面上の2点だけで爪を置く」素朴な方式のほうでした。

旧版からの差分は次の3点だけです。

1. **デザインを12種 → 24種に追加**
   すけ感／ミラーフレンチ／パール／スターダスト／マット／ベルベット／大理石／
   ニュアンス／べっ甲／チェック／ワイヤー／シェル
2. **マット・ベルベットはツヤのハイライトを描かない**
   （デザイン側にフラット化を持たせないとマットにならないため）
3. **カラーにカラーピッカーを追加**
   iOSで確実に開くよう、`input type="color"` そのものを色チップとして表示

爪の形6種（ナチュラル／ラウンド／アーモンド／スクエア／バレリーナ／ポイント）と
長さスライダーは、旧版の `long.html` にあったものをそのまま使っています。

## 使うもの

- MediaPipe Hands 0.4（旧版と同じ）
- 2Dキャンバス描画（WebGLは使っていない＝ブラウザ差が出ない）

## ローカルで試す

`艶II_ローカルで開く.command` をダブルクリック。終了は開いたターミナルで `control + C`。
（カメラを使うため、`file://` で直接開くと動きません）
